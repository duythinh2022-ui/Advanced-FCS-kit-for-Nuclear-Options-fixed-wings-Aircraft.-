## 3. NA MPO

MpoRollMode already defaults to SeparateRollYaw (stick = velocity-vector roll, pedals = body yaw rate) for every jet. A single-engine
3D-TVC jet (pitch + yaw nozzle, one engine — the NA; the B too only if YawTvc is switched on in dev) now flies that law in MPO whatever
MpoRollMode is set to (mpoSep3d). The NA's pedal body yaw has the nozzle's yaw axis in the allocator.

Bench, MPO, 0.4 aft stick, 1 s full pedal tap:

| jet / ias | yaw rate max | sideslip max | 5 s after |
|---|---|---|---|
| B 200 | 18.8 | 10.2 | departed (AoA 23, beta 29, 76 km/h) |
| B 400 | 51.2 | 36.1 | departed (AoA 93, 55 km/h) |

Holding full pedal 3 s at 400 km/h tumbles the NA (no sideslip bound on the MPO pedal, by design since Revoker 0.2.7).

## 4. The two plugins

| | FS-20 Vortex FCS | FS-20 Vortex Family FCS |
|---|---|---|
| DLL | Vortex_FS20_FCS.dll | VortexFamily_FS20_FCS.dll |
| GUID / Harmony id | Vortex_FS20.FCS / tom.vortex_fs20.fcs | Vortex_FS20.FCS.Family / tom.vortex_fs20.familyfcs |
| namespace | Vortex_FS20.FCS | Vortex_FS20.FamilyFCS (renamed at build) |
| config | Vortex_FS20.FCS.cfg (+ .Dev) | Vortex_FS20.FCS.Family.cfg (+ .Dev) |
| telemetry | Vortex_FCS_*.csv | VortexFamily_FCS_*.csv |
| native core | embedded Vortex_FcsCore.dll | separate VortexFamily_FcsCore.dll beside the plugin (same attested bytes, renamed); C# if absent |
| flies | every FS-20 Vortex | family A / C / T / NA only |

Hand-over (FamilyCompat.Decide, once, both sides, logged): FcsBuildInfo.FamilyFingerprint = sha256 over the plugin's C# source (minus
FcsBuildInfo.cs, FcsVersion.cs and whatever family-fingerprint-exclude.txt lists) and the native core's Rust source, generated by
tools/gen_buildinfo.py at build. Both 0.7.1 DLLs: b0dcb4c4dde9de4c (60 files).

- Family FCS alone: it flies A / C / T / NA; the B stays with the game.
- Both, fingerprints equal: the FS-20 Vortex FCS flies everything, the Family FCS stands by.
- Both, fingerprints differ: FS-20 Vortex FCS = B, Family FCS = A / C / T / NA.
- FS-20 Vortex FCS without a fingerprint (0.7.0 or older): the Family FCS stands by and logs why.
- "Only changes the B part": list those files in family-fingerprint-exclude.txt; the fingerprint then still matches. Empty in 0.7.1
  (every file can run on a family jet).

Shared hooks: every patch checks Registry.IsF22, which now includes FamilyCompat.Responsible, so each plugin acts only on its own jets.
Turbojet.FixedUpdate is transpiled by both: the second chains onto the first's TvcPitch / Roll / Yaw / NozzleSlew (0.6.x code) and now
also EngineThrottle / EngineAxis1 (STOVL). The family-mod gates (envelope, elevon remap, sampling) are prefixed by both; each skips the
family code only for a jet it flies.

Build: `bash build.sh Vortex_FS20.FCS out.dll` (FS-20 Vortex FCS), `bash build-family.sh outdir` (Family FCS + its dev unlock).
